# Yandex Station Advanced

Экспериментальная версия 2.0.0-preview.5 для передачи звука Windows на Яндекс Станции.

**Треск, прерывания звука и рассинхронизация между колонками остаются нерешёнными.**
Импорт исходников не исправляет эти дефекты. Физические Станции в ходе импорта не тестировались.

Основной код находится в `advanced/`, `station_bridge/`, `web/` и `installer/`.
Изолированный исходный PCM 1.0.6 находится в `reference/pcm-1.0.6/` и нужен для сравнения.
Это не заявление о его стабильности.

Существующий `LICENSE` и четыре исходных Git-коммита сохранены без изменений.
Уведомления авторов импортируемых исходников находятся в `licenses/` и каталоге PCM 1.0.6.
Происхождение и контрольные суммы импортированных файлов записаны в `SOURCE_IMPORT.json`.
