Системный звук

Захват звука выбранного выхода Windows.

Тестовый режим

Сначала включите музыку на компьютере. Поиск измеряет все выходы 4 секунды, не сохраняет и не передаёт звук. Не выключайте звук браузера/плеера через Mute.

Выбранный источник будет проверен при запуске.

Сигнал выбранного выхода—

Прямой MP3 отправляется без HLS-сегментов. Если колонка его не воспроизводит, вернитесь к HLS. Буфер внутри Станции программой не измеряется.

Меньше очередь — меньше запас при скачках нагрузки. При щелчках выберите «Устойчивый». Для HLS профиль всегда устойчивый. В быстром профиле Windows запрашивается таймер 1 мс только на время трансляции: возможно увеличение энергопотребления.

«К живому звуку» перезапускает поток без старой очереди; возможна пауза. Используйте при накопившемся отставании, а не постоянно.

Очереди на ПК

Измерения появятся после запуска. Это не задержка от компьютера до динамика Станции.

Сравнить задержку Wi-Fi и Bluetooth: сигнал и индикатор. Это отдельная страница без микрофона. Не закрывайте основную панель во время трансляции.

Проверка HLS без захвата Windows

Программа создаёт негромкий тон и передаёт его тем же HLS-способом. Захват Windows не включается. Тест завершится автоматически примерно через 30 секунд. Если этот тон слышен, а музыка нет — проверьте источник Windows.

Буфер HLS
Это не замена проводной аудиокарте. PCM дополнительно убирает кодировщик, но прошивка Станции может сохранять собственный буфер. Достижение задержки Bluetooth не подтверждено. Нулевая задержка не обещается. Не считайте этот режим пригодным для игр и видеосвязи без измерения на вашей колонке.

Трансляция может включать разговоры и уведомления. Захват запускается только кнопкой. Микрофон не используется. Звук на самом ПК автоматически не отключается.
