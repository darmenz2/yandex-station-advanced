# Архивные материалы

Эта папка хранит оригинальные документы из ZIP-снимка preview.5, без редактирования
их содержания. Они нужны для установления происхождения, а не для объявления
текущей версии стабильной.

`preview5-README.md` — прежнее описание реализации. Некоторые инструкции и утверждения
о поставке относятся к исходному архиву. Текущие инструкции и нерешённые проблемы
описаны в корневом README.

`preview5-PAYLOAD_MANIFEST.json` — манифест прежнего установочного комплекта, включая
не опубликованные в Git двоичные сборки. Это не манифест текущего дерева Git.
Текущая карта импорта находится в `SOURCE_IMPORT.json` в корне.

Старый `validation_preview5/TEST_REPORT.md` сохранён в первоначальном расположении.
Сырые журналы прежних тестов исключены из Git и остаются в исходном ZIP.
Импорт не повторяет автоматически все описанные там эксперименты и не подтверждает
устранение треска или рассинхронизации.
