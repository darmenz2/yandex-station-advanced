# Проверка импорта — 17 сентября 2026 года

## Объём и границы

Импорт подготовлен поверх проверенного состояния GitHub `f5144f925babd1aa1ab6fa3bedbde16363c8896b`.
Прямой доступ Git к GitHub из среды подготовки недоступен, а подключённые операции GitHub
позволяют чтение, но не публикацию. Этот отчёт фиксирует локальную подготовку, **не состоявшийся push**.
Публикация готовых коммитов проверяется отдельно после выполнения обычного push владельцем.

Это перенос исходников, документации и тестов. Алгоритм аудио, коррекция темпа,
обработка групп и протокол взаимодействия с колонками в ходе импорта не переписывались.
Треск, прерывания и рассинхронизация остаются открытыми проблемами.

## История и лицензия

Содержимое Git-объектов получено через операции чтения репозитория и восстановлено
локально. Сначала сверялись SHA blob/tree/commit, затем проверялась связность истории.

```text

f5144f925babd1aa1ab6fa3bedbde16363c8896b  Recover source chunks as artifacts for local integrity verification
```

Все четыре SHA совпали с GitHub, включая объект первого коммита с исходной подписью.
Подпись не создавалась заново. Исходная история разработки, не представленная в GitHub
или ZIP, не выдумывалась. Новый импорт продолжает эту цепочку обычными коммитами.

Корневой `LICENSE` сохранён побайтно; Git blob:
`ffd9482429c2244d7b0b1372e61fe091d60e36ff`.
Другой MIT-текст из основного ZIP перенесён в `licenses/StationBridge-MIT.txt`,
уведомления AlexxIT и лицензия PCM 1.0.6 также сохранены.
Два существовавших workflow не изменены. `git fsck --full --strict` исходной восстановленной
истории завершился успешно; такая же проверка выполняется при упаковке финального bundle.

## Окружение и ограничения

- Linux, Python 3.13.5.
- aiohttp 3.13.3; qrcode 8.2; imageio-ffmpeg 0.6.0.
- pytest 9.0.2, pytest-asyncio 1.3.0.

Это **не полное воспроизведение закреплённого `requirements.txt`**: там указан aiohttp 3.14.3,
а в доступной среде был 3.13.3. zeroconf отсутствовал, поэтому реальное mDNS-обнаружение
не проверялось. Закреплённые зависимости проекта не менялись ради прохождения тестов.

Нативное выполнение Windows GUI, WASAPI, QR-вход в реальный аккаунт, микрофон, физические
Станции, радиосеть и акустическая синхронизация не проверялись. EXE проверены компиляцией
и тестами структуры PE, а не запуском в Windows. Успешная программная проверка не означает
устранения пользовательских жалоб и не даёт измерения фактической задержки.
